# Orbit Lab

Orbit Lab is a small interactive learning playground for understanding sorting algorithms visually. The first experiment supports bubble sort, selection sort, and insertion sort with live stepping, speed control, and adjustable array size.

## Run locally

Because this is a dependency-free browser app, serve the repository with any static server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in a browser.
